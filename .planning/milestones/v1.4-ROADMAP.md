# Roadmap: Thai Election Ballot OCR v1.4

## Milestone: Deployment & Security

**Goal:** Make the application production-ready with authentication, optimized Docker images, and comprehensive documentation.

## Phases

### Phase 15: Security & Authentication
**Goal**: Restrict access to the Web UI to authorized users.
**Rationale**: prevent unauthorized uploads or data modification in a deployed environment.
**Plans**:
- [ ] 15-01: Implement HTTP Basic Auth in Gradio (`auth` parameter).
- [ ] 15-02: Support loading credentials from `.env`.

### Phase 16: Container Optimization
**Goal**: Ensure the Docker image supports all new features (OpenCV, PaddleOCR) while minimizing size.
**Rationale**: `opencv-python` requires system libraries; `paddleocr` is large.
**Plans**:
- [ ] 16-01: Update `Dockerfile` with `libgl1` and `libgomp1`.
- [ ] 16-02: Create separate "lite" and "full" (with Paddle) Docker targets.

### Phase 17: Documentation Overhaul
**Goal**: Update README and internal docs to reflect the v1.3 feature set.
**Rationale**: Users need to know about ZIP uploads, caching, and deskewing.
**Plans**:
- [ ] 17-01: Update `README.md` with new features and configuration options.
- [ ] 17-02: Document the `ResultCache` and `PaddleBackend` usage.

## Execution Order

1. Phase 15 (Security)
2. Phase 16 (Container)
3. Phase 17 (Docs)
