# Roadmap: Thai Election Ballot OCR v1.2

## Milestone: Accuracy & Optimization

**Goal:** Improve OCR performance through precise zone cropping and add human-in-the-loop verification tools.

## Phases

### Phase 9: Zone-Based Extraction (Complete)
**Goal**: Implement precise coordinate templates for all 6 ballot form types to improve OCR accuracy and speed.
**Requirements**: ZONE-01, ZONE-02, ZONE-03
**Plans**:
- [x] 09-01: Define and implement coordinate templates for 6 form types
- [x] 09-02: Update OCR backend to use form-specific templates

### Phase 10: Review Queue (Complete)
**Goal**: Add a web interface for users to manually review and correct low-confidence OCR results.
**Requirements**: WEB-09
**Plans**:
- [x] 10-01: Backend API for retrieving and updating specific ballot results
- [x] 10-02: Web UI for side-by-side image/data verification

### Phase 11: Bulk Operations (Partial)
**Goal**: Simplify large batch handling with ZIP uploads and improved memory management.
**Requirements**: WEB-08 (ZIP support)
**Plans**:
- [x] 11-01: Implement ZIP file upload and extraction
- [ ] 11-02: Resume capability for interrupted batches (Deferred to v1.3)

## Execution Order
