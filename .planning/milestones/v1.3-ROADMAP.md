# Roadmap: Thai Election Ballot OCR v1.3

## Milestone: Performance & Intelligence

**Goal:** Maximize OCR accuracy on varied image qualities and significantly improve processing speed.

## Phases

### Phase 12: Adaptive Preprocessing (Complete)
- [x] 12-01: Integrate `adaptive_ocr` logic into `ballot_extraction.py`.
- [x] 12-02: Benchmark accuracy gains on test dataset.

### Phase 12.5: Advanced Vision Preprocessing (Innovative)
**Goal**: Implement structural image corrections to handle real-world scanning imperfections.
**Rationale**: Rotation and table lines are the top causes of "misread" digits.
**Plans**:
- [ ] 12.5-01: Implement `deskew_image` using projection profiles (no Hough transform needed for speed).
- [ ] 12.5-02: Implement `remove_tables` using morphological operations to isolate handwriting.

### Phase 13: Result Caching
**Goal**: Implement a persistent cache (SQLite/File) for OCR results to instant-load previously processed files.
**Rationale**: drastically speeds up development and re-runs of large batches.
**Plans**:
- [ ] 13-01: Implement `ResultCache` class and decorator.
- [ ] 13-02: Integrate cache into `BatchProcessor`.

### Phase 14: PaddleOCR Backend
**Goal**: Implement PaddleOCR as a high-performance local backend.
**Rationale**: PaddleOCR often outperforms Tesseract in speed and accuracy for tables/digits.
**Plans**:
- [ ] 14-01: Create `PaddleBackend` class in `model_backends.py`.
- [ ] 14-02: Add installation instructions and verification script.

## Execution Order

1. Phase 12.5 (Vision Innovation)
2. Phase 13 (Speed)
3. Phase 14 (Alternative Engine)
