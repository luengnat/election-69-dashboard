# Roadmap: Thai Election Ballot OCR v2.2

## Milestone: Structural Refinement

**Goal:** Leverage visual landmarks (Garuda, Dotted Lines) to move from "Box-based" OCR to "Structure-aware" extraction.

## Phases

### Phase 24: Zonal Dotted-Line Extraction
**Goal**: Use dotted line detection to identify exactly where handwritten numbers are located.
**Rationale**: Instead of OCRing a large column, we OCR individual cells anchored to dotted lines. This eliminates "row bleed" errors.
**Plans**:
- [ ] 24-01: Refine `detect_dotted_lines` in `segmentation_utils.py`.
- [ ] 24-02: Implement `extract_zonal_snippets` to produce small images per candidate.

### Phase 25: Multi-Form PDF Splitting
**Goal**: Automatically detect the start of new polling units within a single file.
**Rationale**: Some scans contain multiple units back-to-back. Detecting the Garuda emblem allows us to reset the state and start a new `BallotData` object.
**Plans**:
- [ ] 25-01: Implement `FormSplitter` logic.
- [ ] 25-02: Update `pdf_to_images` or `BatchProcessor` to handle multi-form detection.

## Execution Order

1. Phase 24 (Precision)
2. Phase 25 (Automation)
