# Roadmap: Thai Election Ballot OCR v2.0

## Milestone: Intelligence & Self-Correction

**Goal:** Reach "Human-Level" reliability by implementing recursive self-correction and advanced visual reasoning.

## Phases

### Phase 18: Self-Correction Loop
**Goal**: Automatically detect sum mismatches and re-process problematic images.
**Rationale**: If `Sum(Candidates) != Valid Votes`, we know there is an error. We can retry with higher resolution or different model parameters.
**Plans**:
- [ ] 18-01: Implement `should_retry` logic based on sum validation.
- [ ] 18-02: Implement recursive extraction with "Focused Crops".

### Phase 19: VLM Layout Verification
**Goal**: Use VLMs to verify the *structure* of the form before extraction.
**Rationale**: Ensures we aren't reading a continuation page as a first page or misidentifying form types.
**Plans**:
- [ ] 19-01: Implement "Structural Sanity Check" prompt.
- [ ] 19-02: Integrate with `detect_form_type`.

### Phase 20: Smart Ensemble
**Goal**: Weight the consensus voting based on backend performance.
**Rationale**: Some backends (e.g. PaddleOCR) are better at digits, others (Claude) better at Thai text.
**Plans**:
- [ ] 20-01: Implement per-backend weighting in `model_backends.py`.
- [ ] 20-02: Fine-tune weights using `tests/test_accuracy.py`.

## Execution Order

1. Phase 18 (Self-Correction)
2. Phase 19 (Structure)
3. Phase 20 (Refined Voting)
