# Plan: Accuracy Benchmark

## Objective
Evaluate and compare the accuracy of different OCR backends (Tesseract, PaddleOCR, Ensemble) on the test dataset.

## Context
We need to quantify the improvements from our recent optimizations (Adaptive Preprocessing, Geometric Clustering, Weighted Ensemble) and identify the best-performing strategy.

## Requirements
1.  **Test Dataset**: Use the existing `test_images/`.
2.  **Ground Truth**: Verify `tests/ground_truth.json` covers all test images.
3.  **Metrics**: Calculate:
    -   **Accuracy**: % of ballots where *all* vote counts are correct.
    -   **Field Accuracy**: % of individual vote counts correct.
    -   **Sum Match Rate**: % of ballots where `calc_sum == valid_votes`.
4.  **Comparison**: Run the benchmark for:
    -   Tesseract Only
    -   PaddleOCR (if avail)
    -   Ensemble (Weighted)

## Tasks

### 1. Verify Ground Truth
- [ ] Read `tests/ground_truth.json`.
- [ ] Ensure it matches the actual images.

### 2. Create Benchmark Script
- [ ] Create `benchmark_backends.py`.
- [ ] Iterate through backends:
    -   Configure `EXTRACTION_BACKENDS` env var.
    -   Run extraction on test set.
    -   Compare with ground truth.
- [ ] Generate a markdown report table.

## Technical Details

**Output Format:**
```markdown
| Backend | Ballot Acc | Field Acc | Sum Match % | Time/Img |
|---------|------------|-----------|-------------|----------|
| Tesseract | 80% | 95% | 85% | 1.2s |
| Paddle | 90% | 98% | 92% | 0.8s |
| Ensemble | 95% | 99% | 98% | 2.5s |
```
