# Plan: Advanced Vision Preprocessing

## Objective
Implement structural image analysis to correct skew (rotation) and remove table grid lines, which are major sources of OCR error.

## Context
- **Skew**: Even a 1-degree rotation can cause Tesseract's line segmentation to fail, merging rows or splitting one row into two.
- **Table Lines**: Vertical separators (`|`) are frequently misread as `1` or `l`. Horizontal lines can be misread as `-` or underscore.

## Requirements
1. **Deskewing**: Automatically detect and correct rotation angle (-5 to +5 degrees).
2. **Line Removal**: Detect horizontal and vertical lines and replace them with white pixels, leaving only text/handwriting.
3. **Integration**: Add these as selectable methods in `adaptive_ocr.py`.

## Technical Details

**Deskew Algorithm (Projection Profile):**
1. Rotate image by small angles (e.g. -2 to +2).
2. Project pixels horizontally (sum of row pixels).
3. Calculate variance of projection.
4. Maximum variance = text lines are perfectly horizontal (black text on white lines).

**Line Removal Algorithm:**
1. `thresh = cv2.threshold(...)`
2. `horizontal_kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (40, 1))`
3. `detected_lines = cv2.morphologyEx(thresh, cv2.MORPH_OPEN, horizontal_kernel)`
4. `result = image - detected_lines`

## Constraints
- Must fallback gracefully if OpenCV fails.
- Must be fast (don't try 100 angles).
