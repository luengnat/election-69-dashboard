# Plan: Web UI Authentication

## Objective
Add simple password protection to the Gradio interface to prevent unauthorized access.

## Context
Currently, the Web UI is open to anyone with network access to the port. For a deployed tool handling election data, basic access control is mandatory.

## Requirements
1.  **Mechanism**: Use Gradio's built-in `auth` parameter (`(username, password)` tuple).
2.  **Configuration**: Load credentials from environment variables (`WEB_UI_USERNAME`, `WEB_UI_PASSWORD`).
3.  **Default**: If variables are not set, warn but allow open access (or default to secure random? No, open for local dev is standard).

## Tasks

### 1. Update `config.py`
- [ ] Add `web_ui_username` and `web_ui_password` fields.
- [ ] Read from env vars `WEB_UI_USERNAME` and `WEB_UI_PASSWORD`.

### 2. Update `web_ui.py`
- [ ] Update `demo.launch()` call.
- [ ] Pass `auth=(config.web_ui_username, config.web_ui_password)` if both are set.

## Constraints
- Gradio auth is basic but sufficient for v1.
