# Plan: Zonal Dotted-Line Extraction

## Objective
Isolate individual handwritten numbers by detecting the dotted lines they are written on.

## Context
Thai ballot forms use dotted lines (`................`) for totals and candidate scores. By detecting these lines, we can:
1. Know exactly how many rows are filled.
2. Crop a tight box *above* the line, removing noise from adjacent rows.
3. Improve accuracy by feeding "clean" single-number snippets to OCR.

## Requirements
1. **Robust Detection**: Dotted lines must be detected even if partially covered by handwriting.
2. **Snippet Generation**: Extract a fixed-height region above each line.
3. **Ordering**: Sort snippets vertically to map to candidate positions.

## Tasks

### 1. Refine `detect_dotted_lines`
- [ ] Improve morphological operations to detect "dotted" patterns specifically.
- [ ] Use a kernel that looks for periodic gaps.

### 2. Implement Snippet Extractor
- [ ] `extract_vote_snippets(image_path)` function.
- [ ] Returns a list of (image_snippet, y_coordinate).

### 3. Integration
- [ ] Add a `ZonalBackend` or update `PaddleBackend` to use these snippets.

## Technical Details
- **Kernel**: `10101` pattern detection or dilation followed by standard line detection.
- **Snippet Height**: ~60-80 pixels above the line.

## Constraints
- Hand-written numbers might "hang" below the line or cross it. Need a generous crop.
