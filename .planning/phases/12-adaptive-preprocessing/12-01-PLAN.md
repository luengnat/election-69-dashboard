# Plan: Adaptive Preprocessing Integration

## Objective
Integrate the logic from `adaptive_ocr.py` into the main `ballot_extraction.py` pipeline to dynamically adjust image preprocessing based on input characteristics (resolution, contrast, noise).

## Context
Currently, `_preprocess_image` applies a static set of filters (Contrast 1.8x, Sharpen) to *all* images.
- **Problem**: This over-processes high-quality scans (introducing noise) and under-processes faint, low-quality photos.
- **Solution**: Analyze the image first, then select the best strategy.

## Requirements
1. **Analysis**: Detect resolution (MP), contrast ratio, and noise level.
2. **Strategy Selection**:
   - **High-Res/Clean**: Minimal processing (maybe just resizing).
   - **Low-Contrast**: Adaptive thresholding or contrast boosting.
   - **Noisy**: Median blurring / denoising.
3. **Integration**: Replace the static `_preprocess_image` with `adaptive_preprocess`.
