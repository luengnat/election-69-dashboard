# Plan: VLM Layout Verification

## Objective
Use a Vision Language Model (VLM) to sanity-check the structural integrity of the ballot form before detailed extraction.

## Context
Traditional OCR (Tesseract/Paddle) is "blind" to semantic structure. It might read a "Page 2" header but still try to parse it as "Page 1". Or it might confuse a "Constituency" form for a "Party-List" form if the header is obscured. A VLM can see the "big picture".

## Requirements
1. **Structural Analysis**: Verify:
   - Is this a ballot form?
   - Is it Page 1 or a continuation?
   - Is the table structure intact (header row present)?
2. **Integration**: Run this check *before* the main extraction ensemble if the `form_type` is ambiguous or confidence is low.
3. **Fallback**: If VLM is unavailable (no API key), skip this step silently.
