# Plan: Self-Correction Loop Implementation

## Objective
Implement a recursive extraction logic that detects validation failures (sum mismatches) and automatically retries with alternative strategies.

## Context
Currently, if OCR misreads a number, we log a warning but keep the result. v2.0 will treat a sum mismatch as a trigger for a more intensive "Recursive Extraction".

## Requirements
1. **Detection**: Identify when `calculated_sum != reported_valid`.
2. **Strategy Shift**: On failure, retry with:
   - **Strategy A**: Higher contrast preprocessing.
   - **Strategy B**: Different Vision Model (e.g. use Claude instead of Gemma).
   - **Strategy C**: Zonal zoom (crop closer to the specific column).
3. **Threshold**: Limit to 1 retry to prevent infinite loops and cost explosion.

## Technical Details

**Logic:**
```python
result = extract(img)
if not is_internally_consistent(result):
    result = extract(img, strategy="high_precision")
return result
```

## Constraints
- Must not double-bill API usage excessively.
- Cache should store the *final* corrected result.
