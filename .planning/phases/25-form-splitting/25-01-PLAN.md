# Plan: Multi-Form PDF Splitting

## Objective
Automatically detect and separate multiple election forms (polling units) that have been scanned into a single PDF or image sequence.

## Context
Election officials often scan many units into one long PDF. Our current system treats one file as one unit. We need to detect the "Start of Form" (Landmark: Garuda) to correctly separate the data.

## Requirements
1. **New Unit Detection**: Trigger a new `BallotData` object whenever a Garuda emblem is detected on a non-first page.
2. **Page Grouping**: Group pages between Garuda detections into logical units.
3. **Integration**: Modify the `process_batch` flow to handle one-to-many mappings (1 file -> N units).

## Tasks

### 1. Implement `split_pages_by_landmark`
- [ ] In `segmentation_utils.py`, add a function that takes a list of image paths and returns a list of lists (grouped by unit).

### 2. Update `BatchProcessor`
- [ ] Update `process_batch` to handle the case where a single PDF path yields multiple page-groups.

### 3. Verification
- [ ] Create a "synthetic" merged PDF (Page 1 + Page 1) and verify it produces two results.

## Technical Details
- Landmark: Garuda (Top-center).
- Detection logic: `detect_garuda` (already implemented).

## Constraints
- Some forms might be 1 page, others 4 pages. Garuda is the only reliable "New Unit" signal.
