# Plan: Advanced Segmentation (Garuda & Dotted Lines)

## Objective
Implement structural segmentation using visual landmarks (Garuda Emblem, Dotted Lines) to handle merged files and improve field localization.

## Context
Fixed coordinate crops work well for scanned documents but fail on photos with shift/scale issues. Detecting the Garuda allows us to "re-anchor" the coordinate system. Detecting dotted lines allows us to find exactly where the clerk wrote the numbers.

## Requirements
1.  **Garuda Detector**:
    -   Identify the presence and location of the Garuda emblem.
    -   Use this to split multi-form PDFs (e.g., "Page 1 (Garuda) -> Page 2 -> Page 3 -> Page 1 (Garuda)...").
2.  **Dotted Line Finder**:
    -   Detect dotted underlines (`................`) which indicate input fields.
    -   Crop the region *above* the line for OCR.
